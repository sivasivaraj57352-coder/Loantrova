🔗 **Live website:** https://loantrova.netlify.app

A loan finder that shows which Central Government, Tamil Nadu Government and bank loans you may qualify for.

## Problem
Many students, backward class families and workers don’t know about government loan schemes and end up taking costlier loans.

**Domain:** FinTech · Financial Inclusion | **Category:** Software

## Features
- Eligibility check by age, gender, community, occupation, income and credit score
- English and Tamil
- Eligibility, benefits, documents and official website for each loan
- EMI calculator
- Document checklist to print or share
- Sample profiles for a quick demo
- Light and dark mode
- No sign-up, name or phone number needed

## How it works
1. **Profile:** enter your details
2. **Check:** eligibility rules run in your browser
3. **Results:** see matching loans
4. **Action:** view the document checklist

## Tech stack
HTML, CSS and JavaScript in a single file, hosted on Netlify.

## Run locally
Download this repository and open `index.html` in a browser.

## Limitations
- Scheme details need a review every 3 months.
- Some details, including some credit limits, are not yet verified.
- Results are guidance only, not loan approval. Confirm with the official website or bank.
